# Temperature Trends Analysis

## About the Project

This project began as an Excel-based temperature trends analysis.

The original analysis used Microsoft Excel features such as pivot tables, charts, conditional formatting, and data validation.

I am now organizing and improving the project using GitHub and Python to demonstrate data analysis and visualization skills.

## Original Work

The original Excel analysis is available here:

`docs/original_excel_analysis.pdf`

## Planned Analysis

- Calculate average temperatures by state.
- Analyze average temperatures by month.
- Identify the highest and lowest temperature records.
- Visualize temperature trends using Python.
- Explore the dataset using Pandas.
